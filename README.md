# wifi-audit

Аудитор паролей Wi-Fi. Проверяет пароль на слабость: словарь топ-10000, паттерны дат/лет/последовательностей, русские имена, энтропия.

Только **Python stdlib** — никаких зависимостей.

## Использование

```bash
# интерактивный ввод (пароль не отображается)
python audit.py

# передать пароль аргументом
python audit.py "МойПароль123"
```

## Что проверяется

- Длина (< 8 — критично, < 12 — минимум, < 16 — нормально, 16+ — хорошо)
- Классы символов: строчные / заглавные / цифры / спецсимволы
- Энтропия по набору символов (биты)
- Наличие в топ-10000 самых распространённых паролей
- Словарная основа + суффикс из цифр/символов
- Русские / латинские имена (~200 вариантов)
- Паттерны: годы 1990–2026, даты, qwerty, йцукен, повторы

## Пример вывода

```
=== WiFi Password Auditor ===

Размер словаря: 9999

=============================================
Оценка: 38/100 — СЛАБЫЙ
=============================================

Анализ:
  - длина 9 — минимум-минимум для WiFi, лучше 12+
  - всего 2 класса символов — используй буквы+цифры+спецсимволы
  - энтропия ~47 бит (оценка по набору символов)
  - содержит год 2023 (частая маска)
```

## Структура

```
audit.py            главный скрипт
dict-top10000.txt   словарь топ-10000 паролей
```

> ⚠️ Это не полный перебор WPA-PSK. Для брутфорса — hashcat + rockyou.
